# python-learning-website
Beginner-friendly Python learning website built with HTML, CSS, JavaScript, Flask, and interactive coding features.

## Built With
- HTML
- CSS
- JavaScript
- Python
- Flask
- Pyodide

## Features
- Beginner Python lessons and structured learning sections
- Interactive quiz pages to test user knowledge
- Built-in Python code tester allowing users to enter and run their own code
- Interactive navigation and user-friendly interface
- Backend functionality using Python and Flask

## What I Learned
- Strengthened my HTML and CSS skills through responsive web design
- Improved understanding of backend integration using Python and Flask
- Gained experience creating interactive learning features and quiz pages
- Practiced debugging and problem-solving throughout development
- Used AI-assisted tools to help debug code and support development of the Python code tester
