Functions and Global Variables

What is an function?

Functions allow you to group code together and reuse
it whenever you want. This helps keep programs organized
and easier to read.

Example:
def greet():
   print("Hello!")

greet()

To run a function in Python, you call it by writing its name followed by parentheses, like greet().
This tells Python to get/run the code inside the function.

Output:
Hello



Why Functions Are Helpful?

Functions help because they:

• Reduce repeated code
• Make programs easier to understand
• Break large programs into smaller pieces
• Help organize your code and keep it cleaner




Return vs Print

Knowing the difference between print and return in functions is important because they affect how your program
works. If you only use print, the value just shows up and can’t be used again. But with return, the function
gives the value back so you can store it, reuse it, or use it in other parts of your code. Understanding this
helps you build functions that actually do something useful, not just display output.


print() shows output to the user.

Example:
print("Hello")
Output:
Hello


return sends a value back to the program.

Example:
def add(a, b):
   return a + b

result = add(2, 3)
print(result)
Output:
5



Global Variables

A global variable is a variable created outside a function that can be used anywhere in the program.
This allows different functions to share the same data. However, using too many global variables can cause problems,
since changes in one part of the code can affect other parts.

Example:
x = "Python"

def my_function():
   print("I am learning " + x)

my_function()
Output:
I am learning Python

Explanation:

• The variable x is created outside the function.
• Because it is outside the function, it becomes a global variable.
• The function can still use the variable even though it was not created inside the function.
• Global variables can be accessed by any part of the program.
