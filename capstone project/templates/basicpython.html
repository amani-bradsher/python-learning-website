Basic of Python


Python Files

Every Python program is saved with the file extension .py. This tells the computer that
the file contains Python code.

Example:

hello.py
game.py
calculator.py

When you run the file, the Python interpreter reads the code from top to bottom and executes the instructions.




Indentation

Indentation means spacing at the beginning of a line. Python uses indentation to show
which lines of code belong together.

Example:
if 5 > 2:
    print("five is greater than two")
Output:
five is greater than two

The space before print() shows that the line belongs to the if statement.
If indentation is missing or inconsistent, Python will give an error.

* Most programmers use 4 spaces for indentation.




Variables

Variables are used to store values so they can be used later in the program.
Think of a variable like a labeled box where you store information.

Example:
x = 5
popsicle_color = "orange"

print(x)
print(popsicle_color)
Output:
5
orange

In this example:
- x stores the number 5
- popsicle_color stores the value orange

So basically, when the program runs:
- If you use x, it will output 5
- If you use popsicle_color, it will output orange


Rules for variable names: 
- Cannot contain spaces          
- Cannot start with a number      
- Cannot contain dashes          
- Usually written in lowercase        
with underscores      

Examples of variable names:

student_name
# will work

2studentname
# will not work because of the number in front

favorite_food
# will work

favorite food
# will not work because of the space

game_score
# will work

game-score
# will not work cause of the dash




Comments

Comments are notes written in code that Python ignores when the program runs. Comments can also be used to
temporarily turn off parts of code while testing.

They are used to:

• Explain what the code does
• Leave reminders for yourself
• Make programs easier for others to understand

Example:
# Comments are not shown in the output. print("Hello") # print("fun")
Output:
Hello

* Comments can be written anywhere in your code, and anything after a # will not be shown when the program runs.




Output with print()

The print() function displays information on the screen.

Example:
print("Code is Fun")

or

name = "Alex"
print(name)

Output:
Code is fun

and

Alex
