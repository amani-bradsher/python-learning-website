Variables

What Are Variables?

Variables are containers that store data values so they can be used later in a program. You can think of a
variable like a labeled box where you keep information, and you can open that box whenever you need to use
what’s inside. This makes your code easier to work with because you don’t have to keep typing the same value
over and over again.
Variables can store different types of data, like numbers, text, or even true and false values. Once a variable
is created, you can also change what it stores later in the program if needed.

Example:
age = 16
name = "Jordan"

In this example, the variable age stores the number 16, and the variable name stores the text "Jordan". Later in the
program, you can use age and name instead of typing the values again, which makes your code cleaner and easier to understand.

So if we do the print function we will get an output of the stored data

Example:
age = 16
name = "Jordan"
print(age)
print(name)
Output:
16
Jordan


Casting

Casting allows you to change the data type of a variable into another type. This is helpful when data needs to be
used in a different way inside a program. For example, a number can be turned into text, or text can be turned
into a number so math can be done with it.

- str() converts a value into a string

- int() converts a value into a whole number

- float() converts a value into a decimal number

Example:
age = int("16.1")      # 16
price = float("4.99")  # 4.99
score = str(100)       # "100"

In this example:
- The string "16" is converted into the integer 16.
- The string "4.99" is converted into the float 4.99.
- The number 100 is converted into the string "100".



Assigning Multiple Variables

You can assign values to multiple variables in one line instead of writing separate lines for each one. This
helps make your code shorter and cleaner.

Example:
first, second, third = 1 , 2 , 3
print(first)
print(second)
print(third)
Output:
1
2
3

What is happening:

• first gets the value 1
• second gets the value 2
• third gets the value 3


Python matches each variable to a value in order. So the first variable gets the first value, the second gets the
second, and so on.

* This only works correctly if the number of variables matches the number of values. If they don’t match, Python
will give an error.


Assigning the Same Value

You can also give multiple variables the exact same value in one line.

Example:
x = y = z = 100
print(x)
print(y)
print(z)
Output:
100
100
100

What is happening:

• x, y, and z all point to the same value 100


* This is useful when you want to set default values or initialize multiple variables quickly.



Unpacking a List

Unpacking means taking values from a list and putting them into separate variables.

Example:
sports = ["Basketball","Soccer","Tennis"]
s1, s2, s3 = sports
print(s1)
print(s2)
print(s3)

What is happening:

• s1 gets "Basketball"
• s2 gets "Soccer"
• s3 gets "Tennis"

Output:
Basketball
Soccer
Tennis

As you can see python goes through the list and assigns each item to a variable in order.
