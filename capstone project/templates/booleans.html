Booleans

What are booleans?

Booleans represent True or False values in Python. They are used when a program needs
to check if something is correct or meets a condition, such as comparing two numbers.
Many comparisons in Python return a Boolean value of True or False.

Example:
print(5>2)

When Python compares two values, the result is a Boolean.
This means it will return either True or False depending on the comparison.


You can use different comparison operators like:

   • > greater than
• < less than  
• == equal to 
    • != not equal to

Example:
print(3==3)
print(7<4)
Output:
True
False

* Booleans are important because they are used in decision making, like in if statements, where your program
chooses what to do based on True or False.




bool() Function

The bool() function can test a value and return True or False. It is used to check if something has a value or not.


Checking Values with bool():

• Any number except 0 → True
•  0   →    False      
• Any string except "" → True
• Empty lists or strings → False

Example:
print(bool(5))    # True
print(bool(0))    # False
print(bool("hi")) # True
print(bool(""))   # False
Output:
True
False
True
False



isinstance()

The isinstance() function checks if something is a certain data type. This helps you make sure your program is
using the correct type of data.

Example:
x = isinstance(5, int)
print(x)

It will return True if the value matches the data type, and False if it does not.




Operators for Comparing and Checking Values

Python uses special operators to compare values and test conditions. These operators help programs
determine whether something is true or false.


Python Logical and Membership Operators

Operator Description
and Returns True if both statements are true
or Returns True if one of the statements is true
not Reverses the result, returns False if the result is true
is Returns True if both variables are the same object
is not Returns True if both variables are not the same object
in Returns True if a sequence with the specified value is present in the object
not in Returns True if a sequence with the specified value is not present in the object
