Basic Arithmetic Operations


Python Math operations

Python can perform many mathematical operations, just like a calculator.This means you can use Python to solve
math problems such as addition, subtraction, multiplication, and division. Instead of using a physical calculator,
you can type the problem into Python and it will give you the answer instantly.


Basic math operations

Operation Example Output Description
Addition print(4 + 3) 7 Adds numbers
Subtraction print(10 - 4) 6 Subtracts numbers
Multiplication print(6 * 2) 12 Multiplies numbers
Division print(5 / 3) 1.6667 Normal division(float)
Floor Division print(5 // 3) 1 Integer division (rounds down)
Modulus print(5 % 3) 2 Remainder


Order of Operations

Python follows the order of operations (PEMDAS), just like in math. This means that some operations are done before
others. For example, multiplication and division are done before addition and subtraction unless you use parentheses.

Example:
print(2 + 3 * 4)

Even though it might look like you should add first, Python multiplies first:
• 3 * 4 = 12
• then 2 + 12 = 14

If you want the addition to happen first, you can use parentheses to change the order:

Example:
print((2 + 3) * 4)
Output:
20

Parentheses tell Python what to solve first, just like in regular math. This is important because it can completely
change your answer.




Math With Variables

You can also use variables in math calculations. Variables let you store numbers and then use them in math problems
later. Think of a variable like a labeled box that holds a value.

Example:
x = 10
y = 5
print(x + y)
Output:
15



Updating Variables

Variables can change as your program runs. This means you can update a value instead of making a new variable each time

Example:
x = 10
x = x + 5
print(x)
Output:
15

In this example, Python takes the current value of x, adds 5, and stores the new value back into x.

You can also write this in a shorter way:

x = 10
x += 5
print(x)

Updating variables is useful for keeping track of things like scores, totals, or counts in a program.
