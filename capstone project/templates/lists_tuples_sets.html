Lists, Tuples, and Sets

What are lists, sets,and tuples?

Python has different types of collections for storing data. Three common ones are lists, sets, and tuples, and each
one is used in a slightly different way.


Lists

A list is an ordered collection of items. Lists are changeable,
meaning you can modify them after they are created.

Lists are written using square brackets [].

Example:
colors = ["red", "blue", "green"]
print(colors)
Output:
['red', 'blue', 'green']



Tuples

A tuple is similar to a list, but it cannot be changed after it is created. Tuples are called immutable,
which means their values stay the same.

Tuples use parentheses () instead of square brackets.

Example:
point = (3, 5)
print(point)
Output:
(3, 5)

* If you try to change a value in a tuple, Python will give an error.




Sets

A set is another type of collection that stores multiple values, but it works differently from lists and tuples.
Sets do not allow duplicate values, and they do not keep items in a specific order.

Sets have two important rules:

• Sets are unordered
• Sets do not allow duplicate values

Sets are written using curly brackets {}.

Example:
nums = {1, 2, 2, 3}
print(nums)
Output:
{1, 2, 3}

* If you add duplicate values, Python will automatically remove them.
That is why the second "2" is not present
