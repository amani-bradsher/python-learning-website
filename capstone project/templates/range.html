What is a range?

The range() function is used to generate a sequence of numbers. It is most commonly used with loops, especially
for loops, to repeat code a specific number of times. It helps control how many times the loop runs and can also set a starting and ending point for the numbers.

Example:
for i in range(5):
   print(i)

Output:

0
1
2
3
4



Starting and ending values

You can also tell Python where the range should start. By giving range() two numbers, you can set both the starting
and ending values, which gives you more control over the loop.

Example:
for i in range(2, 6):
   print(i)

Output:

2
3
4
5

The first number (2) is the starting point, and the second number (6) is the stopping point.
The stopping number is not included.




Using range with lists

range() can also be used to loop through items in a list. Instead of going through each item directly, it lets you
loop using the index positions of the list.

Example:
fruits = ["apple", "banana", "orange"]
for i in range(len(fruits)):
   print(fruits[i])

In this example, len(fruits) tells Python how many items are in the list, and the loop prints each one.

Output:
apple
banana
orange

Explanations:

• len(fruits) gives the number of items in the list
• range(len(fruits)) creates a sequence of numbers like 0, 1, 2
• i is used as an index, which means it tells Python which position
    in the list to look at.
• fruits[i] gets the item at that position:
    * when i = 0 → "apple"
    * when i = 1 → "banana"
    * when i = 2 → "orange"




Why range is useful

The range() function helps programmers:

• Repeat code a specific number of times
• Work with numbered sequences
• Loop through lists or data sets

Range is commonly used in programs that require counting, repeating actions, or processing multiple pieces of data.
