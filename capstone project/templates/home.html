Intro to Python

Python is a popular programming language used in many areas such as data science, machine learning,
game development, and software engineering. Python was created in the late 1980s by Guido van Rossum
and officially released in 1991.

Python is known for being simple and easy to read, which makes it a great language for beginners.
Python can run on many different platforms such as Windows, Mac, Linux, and Raspberry Pi.

In this course you will gain a better understanding of Python and how to put programs together. At the end
of each section there will be quizzes to test your knowledge and help you review what you learned.
