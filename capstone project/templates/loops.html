Loops and if statements

What are if statement ?

If statements allow a program to make decisions based on conditions. An if statement normally checks if a condition is true before running code.

if statement example :

age = 19
if age >= 18:
    print("You can vote")
Output:
You can vote

If the condition is true, the message prints. You can also use else.

if statement + else Example:
age = 17
if age >= 18:
    print("You can vote")
else:
    print("You are too young to vote")
Output:
You are too young to vote
>


What are loops ?

Loops repeat code automatically instead of writing the same line many times. They make programs shorter and
easier to read. Instead of repeating code, a loop runs it for you multiple times, which is helpful for things
like counting or going through items in a list.



For Loops

A for loop is used when you want code to repeat a certain number of times. Instead of writing the
same line of code over and over, a loop can do it automatically.

A for loop goes through a sequence of values and runs the code once for each value.

For loop example:
for x in range(3):
   print("Learning Python")
Output:
Learning Python
Learning Python
Learning Python

In this example, the range(3) tells Python to repeat the loop three times.
The variable x is used to keep track of each loop iteration. Python automatically changes the value of x each time the loop runs.


Example showing the value of x:
for x in range(3):
   print(x)
Output:
0
1
2

Python starts counting at 0, which is why the numbers go from 0 to 2 instead of 1 to 3. For loops are often used when working with lists, ranges, or repeating tasks.




While Loops

A while loop repeats code as long as a condition is true. This means the loop will keep
running until the condition becomes false.

Example:
count = 1
while count < 4:
   print(count)
   count += 1

In this example:

• The variable count starts at 1
• The loop runs while count is less than 4
• Each time the loop runs, count increases by 1


This is important because it eventually makes the condition false, which stops the loop. If the value never changes, the loop would run forever. This is called an infinite loop.

Example of an infinite loop:
while True:
   print("This will run forever")

Because the condition is always True, the loop never stops.
Now it will forever print the outcome of "This will run forever" until the program is turned off.
