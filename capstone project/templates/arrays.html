Arrays

What are arrays?

An array is a way to store multiple values inside one variable instead of creating many separate variables.
Arrays are useful when you are working with a group of related data.

For example, instead of doing this:
score1 = 85
score2 = 90
score3 = 78
You can store them together in one array:
scores = [85, 90, 78]



Arrays in Python

In Python, arrays are usually created using lists. Lists act like arrays because they can hold multiple values
in one place.
The values inside an array are called elements, and each element has a position number called an index.
Python starts counting indexes at 0 instead of 1.

Example:
fruits = ["apple", "banana", "orange"]
print(fruits[0])
Output:
["apple", "grape", "orange"]

Explanation:

• The list starts with "banana" in position 1
• We change that value to "grape"
• The list updates right away without creating a new one




Changing values in an array

Arrays in Python can be modified, which means you can change values even after the list has already been created.
This is possible because lists are changeable, so you don’t need to create a new list just to update something.

Example:
fruits = ["apple", "banana", "orange"]
fruits[1] = "grape"
print(fruits)
Output:
['apple', 'grape', 'orange']



Looping through an array

Arrays in Python are often used with loops to go through each item one at a time. This helps you work with every
value in the list without having to write separate code for each one.

Explanation:

• The loop goes through each item in the list
• Each item gets stored in the variable fruit
• The print() line runs once for every item

Example:
fruits = ["apple", "banana", "orange"]
for fruit in fruits:
   print(fruit)
Output:
apple
banana
orange
